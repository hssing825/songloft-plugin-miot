# 智能音箱播放页歌词

智能音箱插件的播放页通过主程序的 `/api/v1/songs/{id}/lyric` 读取歌词。歌曲没有已有歌词时，主程序会调用已注册的歌词搜索插件；搜索命中后由主程序缓存到曲库，智能音箱插件无需单独配置歌词提供商。

1. 安装并启用「歌词搜索」插件。
2. 打开歌词搜索插件的配置页，勾选「启用歌词搜索」并保存。仅启用插件本身不会开启搜索，默认配置中的搜索开关是关闭的。
3. 在智能音箱插件播放曲库中的歌曲，点击播放器的歌词按钮，或在手机全屏播放页左滑查看歌词。

搜索过程中显示「正在获取歌词…」。未命中时提示检查歌词搜索插件；获取失败时显示错误，并可点击「重新获取歌词」重试。重试通过主程序的 `refresh=1` 重新搜索，主程序仍保护文件、内嵌及手动歌词。搜索期间切歌或停止后，旧请求不会覆盖当前页。

歌词代理最多等待 30 秒，为主程序每个歌词提供者的 15 秒搜索预算留出空间；多个提供者依次超时仍可能超过代理预算，此时可重试。搜索命中与否取决于歌曲元数据、提供商收录和网络情况。

此处显示的是插件网页歌词；触屏音箱本机歌词另由设置中的「触屏音箱显示歌词」控制，依赖设备的 Music API 及云端曲库匹配。未入库的外部直推歌曲没有有效曲库歌曲 ID，不能通过此接口搜索歌词。
