# Dev Flow

先检查本仓库工作树，读取 AGENTS、适用 LESSONS 与 [本地 AI 流程](../../../docs/ai-development.md)；任务需要的业务/平台文档按 AGENTS 导航加载，宿主契约核对父仓库。

## 连续执行

- 任务授权后连续调查、方案、实现、格式化、验证、自审和交付，不逐阶段等待确认。关键缺失信息、产品决定、确需扩大范围时才询问；等待期间继续独立工作，保留用户修改与已完成证据。
- 命令与平台闸门按本地 AI 流程和 AGENTS；编译、单元测试、模拟接口、浏览器与真机的覆盖边界分别记录。Bug 新测试在隔离旧实现下按预期行为失败，新实现下通过；按风险做破坏检查。
- 记录仓库、SHA 或未提交工作树标识、时间、环境、命令、实际结果与相关 Not run；代码、生成物、依赖或子模块改变后重跑受影响项。必要验证缺失时报告阻塞，不冒充通过。
- 自审最终 diff 和同类调用点，能修则修并重新验证；同步本地对应中英文业务文档，执行差异/编码检查。插件与后端独立升级；记录设备型号/固件、音频来源、插件/后端版本和已安装提交。云端回执不等于设备发声，模拟进度不等于真实采样。真实音箱或问题音频未验时写 Not run，保留历史回归矩阵。

## 跨仓库排查与复盘

- 未解决 Issue 排查包含父仓库与全部递归子模块，不只当前仓库；从父 .gitmodules 发现、去重、完整分页，保留负责人。父工作区使用 ai-review-context.mjs issues，独立 checkout 从父清单与 GitHub 只读 API 补齐范围。
- 逐项读取正文、全部评论、关联修复/复发证据与最新远端代码，按本地指南分类。完整 owner/repo#编号，父指针、发布、安装版本分开判断，覆盖失败明确报告，open 不等于未修复。
- 任务结束记录有证据的新经验；时间窗口复盘使用父仓库 commits 收集本地历史，标明远端新鲜度与缺口。中英 LESSONS 同步；Seen 统计不同日期的独立事件，同事故重复复盘不递增。三个日期提出升级，已有铁律/严重问题立即处理，不能虚构次数或自动扩权。

## 交付和授权

授权依据是当前会话中的用户指令；旧 handoff/progress 的授权说明只是历史证据，不授权本批提交或外部动作。

调查、修改、验证和自审已获任务授权后直接完成。交付变化、验证记录、剩余问题与中文 Conventional Commit 信息。直接提交 main，不加 Co-Authored-By；跨仓库引用必须完整。

提交、推送、正式发布、Issue 评论/关闭分别需要明确授权，已有授权不重复询问。只 stage 本次文件；子仓库先提交、父仓库再更新指针。尚未提交时报告 dirty 子模块。推送后追踪同一 SHA 的必要 CI，取消/跳过不算通过。排查默认报告，不擅自领取/修复任意 Issue。
